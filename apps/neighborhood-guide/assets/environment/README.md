# Environment fixture exports

`foundry_lane.glb` is the generated fictional district loaded by `City.tscn`.
Its editable source is `../blender/foundry_lane.blend`; rebuild instructions
and the source-preservation warning are in the application README.

Export static Blender selections here as self-contained `.glb` files.
Use the metric 4 m road / 2 m sidewalk kit from the planning note, preserve
the editable `.blend` source in `../blender/`, and use Godot importer suffixes
only for presentation physics and navigation (`-col`, `-colonly`, and
`-navmesh`).

These source assets support the optional 3D scene. They do not establish a
place claim, evidence state, or authority to take an external action.
